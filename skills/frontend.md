# frontend — 前端界面 skill

## 约束
- 不新增全局样式；组件样式随组件文件组织
- 保持既有公共组件 props 签名稳定；确需改动走 L3 审批
- 任何网络请求必须有加载/错误/空态三种处理

## 偏好
- 优先复用既有组件与 hooks，再考虑新建
- 状态尽量局部化，避免无谓的全局 store 改动
- 文案集中管理，不散落在 JSX 里

## 输出规范
- 每个页面级交付物独立成段（SEGMENT），可单独验收
- 新增组件附带最小可渲染示例与对应测试文件
- 交互验收标准写成可执行命令或明确步骤（进 acceptance.md）

## 反例
- 为一个按钮改动整个设计系统 token 文件
- 引入新 UI 框架来解决一个局部样式问题
