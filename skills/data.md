# data — 数据处理与分析 skill

## 约束
- 管道必须幂等可重跑；中间产物落盘可校验
- 不改既有表结构/schema；确需迁移走 L3 审批（modify_schema）
- 大文件处理必须流式或分块，禁止一次性读入未知大小数据

## 偏好
- 优先 SQL/既有管道改造，避免新建平行数据链路
- 指标口径写在 docstring，与验收标准一致
- 输出图表/报表配一个最小样例数据便于验证

## 输出规范
- ETL 脚本按 extract/transform/load 三段组织，每段可独立验收
- 报表交付物注明数据来源、时间范围与刷新方式

## 反例
- 为一份报表复制整套数仓调度配置
- 在生产配置文件里写连接串
