# common — 通用工程 skill（任务命中任意领域时始终附带）

## 约束
- 所有写操作经编排器权限闸门：默认 auto 只拦 L3，禁止 force push / 直推 main
- 改动最小化：只动与本任务相关的文件，不扩大范围、不顺手重构
- 不触碰 CI/config/Dockerfile/lock/密钥类文件，除非任务明确要求并接受审批

## 偏好
- 命名与代码风格随周边代码；注释密度与现有文件一致
- 每段交付完成后自测一次再报告成功
- 拿不准时写 blocked.md 说明，不擅自决定

## 输出规范
- 交付物清单化：新增/修改文件逐一列出，附一行说明
- 验收标准逐条可执行（命令或可观察结果），写入 acceptance.md
- 失败时报告：做了什么、卡在哪、建议的下一步

## 反例
- 未等审批直接改公共接口签名
- 把调试打印、临时文件留在交付物里
