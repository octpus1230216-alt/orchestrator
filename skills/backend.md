# backend — 后端服务 skill

## 约束
- 所有对外接口必须向后兼容；确需改签名走 L3 审批
- 数据库写操作必须在事务内；迁移脚本必须可回滚
- 不得在日志中输出密钥、token、口令等敏感字段
- 并发路径必须显式说明锁/幂等策略

## 偏好
- 优先标准库与既有依赖，避免为小需求引入新包
- 错误处理采用显式返回/抛出，不做静默吞异常
- 每个新功能配一个对应的测试文件，命名 test_<模块>.py

## 输出规范
- 分层组织：路由层薄、业务逻辑放 service 层、数据访问放 repository
- 新增内部工具函数放入既有 utils/ 或新模块，不改公共导出
- prompt 分段时每段对应一个可独立验证的交付物

## 反例
- 为"加限流"顺手重构整个鉴权模块（扩大范围）
- 直接修改 get_user 返回类型而不申请 modify_public_signature
- 把配置硬编码进源码、写进日志
